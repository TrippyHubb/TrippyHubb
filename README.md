## What I work on

- **Internal web apps** that replace shared spreadsheets: performance tracking, staff
  scheduling, approvals and reporting, with role-based access.
- **Data pipelines** that pull from CRM, project-tracking and review sources into
  Postgres every night, so dashboards read numbers instead of people typing them.
- **Automation and alerts**: Slack messages and weekly summaries, Google Sheets sync,
  and scheduled jobs on GitHub Actions.
- **Rules with a record**: month-end locks, approval flows and audit trails, so a result
  can always be explained.

**280+ pull requests** merged into our internal platform in the past year.
